# Assorted Building Blocks

Adds bricks, tiles, columns, beams and panels for every stone and wood, along with a lumber mill that cuts wood the way the stonecutter cuts stone. It also has siding, decorative stone, glass, quartz and steel doors, and a chain link fence and door.

Also included in [Assorted Decor](../decor). Worlds made with Assorted Decor 11.x keep everything when you switch to this mod.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).

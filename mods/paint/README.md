# Assorted Paint

Adds a paint roller and a roller for each of the sixteen colors. Use one on wool, carpet, concrete or concrete powder to recolor it where it sits, or on a sheep to dye it. The colored rollers count as dyes too, so they work in any recipe that takes a dye.

Paint is an add on for the other Assorted Decor mods. With Assorted Roads installed the rollers paint roadways and switch the white line markings. With Assorted Lights they recolor fluro blocks, and with Assorted Building Blocks they give siding its color.

Also included in [Assorted Decor](../decor). Worlds made with Assorted Decor 11.x keep everything when you switch to this mod.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).

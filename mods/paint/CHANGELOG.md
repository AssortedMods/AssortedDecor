# Changelog

## 1.0.0

- First release as its own mod. It used to only be part of Assorted Decor
- Worlds from Assorted Decor 11.x keep all of their paint rollers
- The recipes that paint roadways, fluro blocks and siding only show up when the mod those blocks come from is installed
- Siding can be held together with honeycomb, slime, honey or resin as well as tar, so it no longer needs Assorted Roads
- Requires Assorted Lib 4.3.0
